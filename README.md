

# DIGI4ECO Metadata Specifications #
This repository contains the DIGI4ECO Metadata Specifications, which define how datasets should be structured to be compliant with DIGI4ECO's data policy. The specifications apply to both NetCDF files and datasets served through ERDDAP.  

The specifications are composed by the following:

* **[DIGI4ECO Metadata Specifications](https://github.com/digi4eco/digi4eco-metadata-specifications/blob/develop/DIGI4ECO_metadata.md)**: Specifications main document
* **[DIGI4ECO Codes](https://github.com/digi4eco/digi4eco-metadata-specifications/blob/develop/DIGI4ECO_codes.md)**: List DIGI4ECO codes, including Regional Facilities and sites. 
* **[OceanSITES codes](https://github.com/digi4eco/digi4eco-metadata-specifications/blob/develop/OceanSites_codes.md)**: List of conventions taken from the OceanSITES specifications. 
* **[OceanSITES codes](https://github.com/digi4eco/digi4eco-metadata-specifications/blob/develop/OceanSites_codes.md)**: List of conventions taken from the DataCite Metadata Schema.
